# 定时触发器说明

> 官方统计插件定时任务。`package.json` 内已配置 triggers，上传时一般会自动带上；**测试 → 生产** 后仍请在控制台核对是否生效。

## Cron 表达式（已写在 package.json）

```
19 19 * * * * *
```

| 含义 | 每小时约第 19 分 19 秒执行（插件默认） |
| 作用 | uni-stat 统计汇总 |

## 建议超时 / 内存

| 项 | 建议值 |
|----|--------|
| 超时 | **600s**（与 package.json 一致） |
| 内存 | 512MB |
| 并发 | 1 |

## 注意

勿随意改表达式，除非同步升级 uni-stat 插件文档要求。
