# 定时触发器说明

> **阿里云**控制台格式：`["cron:…"]`，**6** 段。

## 阿里云控制台应填写

推荐与 `withdraw-expire-cron` 错开，用 **00:15**：

```json
["cron:0 15 0 * * *"]
```

若坚持零点：

```json
["cron:0 0 0 * * *"]
```

| 含义 | 每天定点复核近 30 天「本地未到账但微信已 SUCCESS」的提现 |

## 建议超时

**≥ 180s**｜内存 512MB｜并发 1
