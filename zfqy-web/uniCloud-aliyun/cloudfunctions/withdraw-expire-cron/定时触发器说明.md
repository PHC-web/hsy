# 定时触发器说明

> **阿里云**控制台格式：`["cron:…"]`，**6** 段。

## 阿里云控制台应填写（主任务）

```json
["cron:0 0 0 * * *"]
```

| 含义 | 每天 **00:00:00** |

## 可选补扫

```json
["cron:0 5 0 * * *"]
```

```json
["cron:0 10 0 * * *"]
```

（控制台通常只支持一个触发器；若只能配一个，主任务用 00:00 即可。）

## 建议超时

**300s**｜内存 512MB｜并发 1

## 作用

未打款提现自动失效 / 微信撤销确认。
