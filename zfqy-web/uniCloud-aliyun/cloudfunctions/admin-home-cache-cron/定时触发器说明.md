# 定时触发器说明

> 测试 → 生产部署后，在 **uniCloud 控制台 → 本云函数 → 云函数触发器** 中配置。  
> **阿里云**与腾讯云格式不同，请勿照抄 7 段表达式。

## 阿里云控制台应填写（整段复制）

```json
["cron:0 */3 * * * *"]
```

| 含义 | 每 **3** 分钟执行一次（第 0 秒） |
| 格式要点 | ① 必须带 `cron:` 前缀　② 共 **6** 段（秒 分 时 日 月 周）　③ **不要**第 7 段「年」 |

### 常见错误（会报 InvalidTimingTriggerConfig）

```json
["0 0/3 * * * * *"]
```

缺 `cron:`、多了一段「年」，阿里云会直接 400。

## 建议超时 / 内存

| 项 | 建议值 |
|----|--------|
| 超时 | **≥ 300s** |
| 内存 | 512MB |
| 并发 | 1 |

## 作用

预热管理端首页统计到 Redis（数据预览 / 资金汇总 / 提现TOP20 / 待提现与按月冻结 / 图表）。前端约每 5 分钟只读 Redis。

## 依赖

- `merchant`（需绑定 Redis）
- Action：`adminHomeCacheRefresh`
