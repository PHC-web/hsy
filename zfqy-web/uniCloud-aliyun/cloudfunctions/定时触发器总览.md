# 云函数定时触发器总览（阿里云）

测试 → 生产时，业务 cron 请在控制台「云函数触发器」里配置。  
官方说明：https://doc.dcloud.net.cn/uniCloud/trigger.html

## 阿里云正确写法（重要）

```json
["cron:0 */3 * * * *"]
```

| 规则 | 说明 |
|------|------|
| 必须带 `cron:` 前缀 | 否则 `InvalidTimingTriggerConfig` |
| 共 **6** 段 | 秒 分 时 日 月 周 |
| **不要**第 7 段「年」 | 那是腾讯云格式 |
| 「秒」位不要用 `*/n` | 阿里云秒不支持特殊字符；间隔用「分」位如 `*/3` |
| 最短间隔 | 阿里云正式版最低 **1 分钟** |

### 错误示例（会 400）

```json
["0 0/3 * * * * *"]
```

缺 `cron:`、多了一段年。

## 业务定时任务速查

| 云函数 | 控制台粘贴内容 | 周期 | 建议超时 |
|--------|----------------|------|----------|
| `admin-home-cache-cron` | `["cron:0 */3 * * * *"]` | 每 3 分钟 | ≥ 300s |
| `withdraw-sync-cron` | `["cron:0 */5 * * * *"]` | 每 5 分钟 | ≥ 120s |
| `withdraw-expire-cron` | `["cron:0 0 0 * * *"]` | 每天 00:00 | 300s |
| `withdraw-reconcile-cron` | `["cron:0 15 0 * * *"]` | 每天 00:15（与 expire 错开） | ≥ 180s |
| `pending-pay-wx-sync-cron` | `["cron:0 */10 * * * *"]` | 每 10 分钟 | ≥ 120s |
| `merchant-data-correct-cron` | `["cron:0 0 0 * * *"]` | 每天 00:00 | ≥ 600s |
| `points-optimize-cron` | `["cron:0 30 1 * * *"]` | 每天 01:30 | 建议 ≥300s（控制台可更高） |

各目录另有 `定时触发器说明.md`。

## 插件自带（package.json 已含，仍核对）

| 云函数 | 说明 |
|--------|------|
| `uni-stat-cron` | 插件默认；腾讯云式 7 段写在 package，阿里云上传时会转换，以控制台展示为准 |
| `uni-analyse-searchhot` | 每 2 小时热搜归纳 |
