# 慧收盈 H5 商户使用手册

**版本：** 1.0  
**更新日期：** 2026年5月  
**适用对象：** 使用微信公众号进入「慧收盈」的商户（店主、收银员等）  

---

## 一、平台是做什么的？

「慧收盈」是面向商户的**微信 H5 商户中心**，与您的收款机具（码牌）配合使用，主要帮助您：

- 查看收款补贴、积分与奖励  
- 领取交易产生的补贴奖励  
- 购买或升级**额度包**，获得更高交易补贴额度  
- 将积分兑换提现到微信零钱  
- 绑定/管理码牌、查看财务流水  
- 联系客服、办理退款等  

> **重要提示：** 本平台仅针对**正常商户真实交易**进行补贴。套现等异常行为可能触发风控，将无法享受补贴。

---

## 二、如何进入商户中心

### 2.1 推荐方式：在微信中打开

1. 关注慧收盈**微信公众号**（服务号）。  
2. 通过公众号菜单或客服发送的链接，在**微信内置浏览器**中打开商户中心页面。  
3. 首次进入时，系统会引导您完成**微信授权登录**（使用您的微信昵称与头像）。  

> 请务必使用**微信**打开链接。在电脑普通浏览器（如 Chrome）中直接打开，无法正常完成微信登录。

### 2.2 首次使用：绑定机具（码牌）

登录成功后，若尚未绑定机具，页面会提示**「绑定机具」**：

1. 在输入框中填写您的**机具号码**（码牌号，可向业务员或机具包装盒上查看）。  
2. 点击 **「绑定并进入」**。  
3. 绑定成功后自动进入商户中心首页。  

之后可在 **「我的 → 码牌绑定」** 中新增绑定多台码牌，或解绑不再使用的码牌。

---

## 三、界面总览：底部三个标签

进入商户中心后，底部固定有三个标签：

| 标签 | 名称 | 主要作用 |
|------|------|----------|
| 左 | **首页** | 查看会员身份、提现统计、待提现金额、剩余额度、额度包入口 |
| 中 | **收益** | 领取交易补贴奖励（气泡/一键领取）、查看奖励明细 |
| 右 | **我的** | 账户信息、各类功能菜单入口 |

各页面右上角一般有 **「刷新」**，用于更新最新数据。

## 四、首页

### 4.1 顶部信息

- **微信昵称、手机号**（未绑定时显示「手机号未绑定」）  
- **会员级别**（如普通会员、银卡会员等）  
- **品牌名称 · 机具号码**  

部分银卡会员还会显示**当月流水统计**。

### 4.2 提现累积

展示您已到账提现金额的统计（按北京时间自然日/月/年）：

- 今日 / 本月 / 本年  

### 4.3 待提现与剩余额度

- **待提现金额：** 已产生、尚未完成提现流程的金额  
- **剩余提现额度：** 当前还可用于提现的额度上限；若已购买额度包，会显示总额度与已用额度及进度条  

### 4.4 额度包入口

点击 **「额度包」** 卡片，进入充值/升级页面，选择套餐并完成微信支付。

## 五、收益页：领取补贴奖励

### 5.1 页面说明

收益页宣传「商家收款免手续费」等活动信息，核心是：

- 屏幕上的**金色气泡**：每笔待领取的补贴，点击单个气泡可领取  
- **「一键领取」** 按钮：一次性领取全部待领奖励  
- 下方 **「奖励明细」**：已入账的历史记录  

### 5.2 如何领取

1. 打开底部 **「收益」** 标签。  
2. 若有待领奖励，点击气泡或 **「一键领取」**。  
3. 领取成功后，积分会计入您的账户，可在「我的」中查看。  

若无待领奖励，按钮会显示「暂无奖励」。

### 5.3 联系客服

收益页顶部有 **「联系客服」**，点击可拨打客服电话（以页面显示号码为准）。

### 5.4 温馨提示

补贴与您的**真实刷卡/收款流水**相关。请保持机具正常收款；达标后奖励会以气泡形式出现在收益页，请及时领取。

## 七、额度包（充值 / 升级）

### 7.1 进入方式

- 首页 → 额度包卡片  
- 我的 → 额度包  

### 7.2 操作步骤

1. 浏览可选套餐，查看**额度、价格、会员档位、权益说明**。  
2. 点击选择某一档位（高亮表示已选）。  
3. 若套餐含**实物赠品**（如碰一碰音响、扫码 POS 机等），需**任选其一**。  
4. 若您已有较低档位套餐，更高档位可能显示 **「补差价升级」**，只需支付差价。  
5. 点击 **「立即升级」** 或 **「补差价升级」**，按提示完成**微信支付**。  
6. 支付成功后进入 **「充值成功」** 页，可返回首页查看新额度。  

### 7.3 签署协议

首次充值或系统要求时，会弹出 **《开户优惠活动计划书》**：

1. 请仔细阅读协议内容（可上下滑动查看）。  
2. 在底部签名区域**手写签名**并确认。  
3. 签署完成后方可继续支付。  

### 7.4 注意事项

- 不能选择**低于或等于**当前已购档位的套餐重复购买。  
- 赠品发货进度可联系客服查询。  
- 充值与退款周期相关规则，见下文「退款与周期」。

## 八、奖励提现

### 8.1 进入方式

**我的 → 可用奖励**（点击金额区域）→ **奖励提现** 页面。

### 8.2 提现规则（页面展示为准）

- **可兑换积分：** 当前账户可用于提现的积分  
- **会员类型：** 影响单笔最低/最高积分限制  
- **1 积分 = 1 元**（兑换按积分计算）  
- **单笔手续费：** 每笔固定扣除一定金额（以页面显示为准）  
- **办理时间：** 一般为工作日 9:00–18:00（北京时间）；非办理时间无法提交  

### 8.3 操作步骤

1. 在输入框填写要兑换的**积分（整数）**。  
2. 确认在允许范围内（页面会提示本次最低～最高积分）。  
3. 点击 **「提交申请」**。  
4. 若平台开启人工审核，需等待审核通过后，资金才会打款至您的微信零钱。  
5. 可在 **财务管理** 中查看提现记录与状态。

## 九、退款与周期

### 9.1 什么是「退款窗口」

购买额度包后，通常有：

- **锁定期：** 一段时间内不可按正常规则全额退款  
- **开放窗口：** 满期后的一段短时间内，可申请**全额退款**并重置相关权益  

具体天数以页面 **「退款规则说明」** 及您签署的协议为准（常见为满一定天数后开放数天窗口）。

### 9.2 如何进入

- 通过 **售后反馈** 中客服发送的「退款」入口链接  
- 或由运营人员指引的专用链接  

### 9.3 页面内容

- **退款规则说明**（多条文字规则）  
- **查看协议**：查看您已签署的协议  
- 主按钮根据状态变化，例如：  
  - 「申请退款并重置权益数据」  
  - 「审核中」  
  - 「审核通过，点击提取」（需在微信中确认收款）  
  - 「退款已完成」等  

### 9.4 锁定期内退款

若在锁定期内坚持退款，可能需扣除**违约金**后返还剩余款项，具体比例见规则说明。

### 9.5 温馨提示

- 未充值用户无法使用正常退款流程。  
- 退款审核与打款需要一定时间，请耐心等待。  
- 如有疑问，请通过 **售后反馈** 联系客服。

## 十、码牌绑定

**路径：** 我的 → 码牌绑定  

### 10.1 查看已绑定码牌

列表显示机具号、品牌、绑定时间。

### 10.2 新增绑定

1. 在「新机具号」输入框填写机具号码。  
2. 点击 **「新增绑定」**。  
3. 支持绑定**多台**码牌，流水按同一商户合并统计。  

### 10.3 解绑

在对应码牌行点击 **「解绑」**，按提示确认。解绑某一台不影响其他已绑定码牌。

### 10.4 绑定记录

页面下方可查看历史绑定/解绑记录，支持加载更多。

## 十一、财务管理

**路径：** 我的 → 财务管理  

### 11.1 查询流水

1. 选择 **开始日期** 与 **结束日期**（默认约近 90 天）。  
2. 点击 **「查询」**。  
3. 列表展示各类记录：类型、时间、标题、金额、状态等。  

### 11.2 记录类型

可能包括：充值、提现、退款、补贴等相关记录（以页面显示为准）。

### 11.3 待确认收款

部分提现记录在审核通过后，需在列表中**点击该条记录**，按微信提示**确认收款**才能完成到账。

## 十六、售后反馈

**路径：** 我的 → 售后反馈  

### 16.1 发起咨询

- 在底部输入框描述问题，可附带**图片**或**视频**  
- 点击 **「发送」** 即可创建会话  

### 16.2 查看回复

客服回复会显示在对话列表中；有新回复时，「我的」菜单旁可能出现红点提示。

### 16.3 退款入口

客服可能在对话中发送 **「退款」** 按钮，点击后进入「退款与周期」页面（链接有时效，请及时使用）。

### 16.4 结束反馈

问题已解决时，可点击右上角 **「结束反馈」** 关闭当前会话。

## 十七、典型使用场景

### 场景 1：新商户第一次使用

1. 微信打开链接 → 授权登录  
2. 绑定机具号 → 进入首页  
3. 签署协议（如提示）→ 购买额度包（可选）  
4. 正常收款后 → 到「收益」领取补贴  

### 场景 2：每天领取补贴

1. 打开 **收益**  
2. 点击气泡或 **一键领取**  
3. 在 **我的** 查看可用奖励与积分  

### 场景 3：积分提现到微信

1. **我的** → 点击 **可用奖励**  
2. 填写积分 → **提交申请**（注意办理时间）  
3. 如需确认收款，到 **财务管理** 点击对应记录完成确认  

### 场景 4：升级更高额度包

1. **首页** 或 **我的** → **额度包**  
2. 选择更高档位 → 支付差价  
3. 返回首页查看剩余额度变化  

### 场景 5：更换或增加码牌

1. **我的** → **码牌绑定**  
2. 新增绑定或解绑旧码牌

## 十八、常见问题

**Q1：打不开页面或无法登录？**  
A：请确认使用**微信**打开；检查网络；取消后重新从公众号菜单进入。

**Q2：提示要绑定机具，不知道机具号？**  
A：查看码牌机身标签、包装盒或咨询为您装机的工作人员/业务员。

**Q3：收益页没有气泡？**  
A：可能暂无待领补贴，或流水未达标、触发风控；请继续正常收款或联系客服。

**Q4：提现按钮是灰色的？**  
A：可能不在办理时间、积分不足、超出单笔限额，或积分扣除手续费后金额无效。

**Q5：提现提交了，钱没到微信？**  
A：可能待审核、待您确认收款，或银行/微信处理中；请在「财务管理」查看状态，或联系客服。

**Q6：为什么不能退款？**  
A：可能处于锁定期、未在开放窗口内，或尚有进行中的退款单；请阅读「退款与周期」页规则说明。

**Q7：充值时提示要签协议？**  
A：属正常流程，请阅读协议后手写签名再支付。

**Q8：手机号显示未绑定？**  
A：进入 **手机号维护** 填写并保存。

**Q9：平台提示套现将不允补贴？**  
A：请使用机具进行真实经营收款，避免违规操作。
