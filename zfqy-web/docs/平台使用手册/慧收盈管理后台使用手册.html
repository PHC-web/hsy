慧收盈管理后台使用手册

版本： 1.0
更新日期： 2026年5月
适用对象： 运营、客服、财务审核、品牌与机具管理人员等日常使用后台的工作人员

一、平台简介

「慧收盈」管理后台用于日常运营管理，主要包括：

  • 查看经营数据与资金概况
  • 管理品牌、机具与商户
  • 处理商户提现、退款申请
  • 维护商品、额度包、优惠券等营销配置
  • 查询交易账单与流水记录

商户在微信端（H5）完成注册、绑机、充值、提现、退款等操作；本手册说明的是后台网页端的使用方法。

说明： 您登录后左侧菜单可能与他人不同，这是由管理员分配的角色权限决定的。看不到某菜单时，请联系管理员开通。

二、登录与基本操作

2.1 如何登录

  1. 在浏览器中打开管理员提供的后台地址（一般为 /admin 路径）。
  2. 输入账号和密码，点击登录。
  3. 若忘记密码，请使用「找回密码」或联系管理员重置。

2.2 登录后进入哪里

  • 控制台（首页）： 有数据看板权限的用户，登录后通常进入「首页」，可查看统计卡片与趋势图。
  • 门户中心： 仅有部分功能权限的用户，可能进入「门户中心」，以卡片形式展示可进入的功能模块，点击即可跳转。

2.3 界面说明

区域 作用
顶部 显示当前位置（面包屑）、语言/主题（如有）、个人头像与退出
左侧菜单 按模块分类的功能入口
中间内容区 列表、表单、图表等具体操作区域

2.4 列表页的通用操作

多数列表页支持：

  • 表头筛选： 在列标题处输入关键字或选择条件后查询
  • 分页： 底部可翻页、调整每页条数
  • 导出： 部分页面右上角有「导出」，可将当前筛选结果导出为表格文件
  • 刷新 / 重置： 重新加载数据或清空筛选条件

三、控制台（首页）

菜单路径： 首页

用于快速了解整体经营情况，主要包括：

3.1 数据预览

  • 品牌数 / 机具数 / 激活数 / 绑定数
  • 提现成功单数 / 提现成功金额
  • 用户数 / 会员数 / 会员率 等

3.2 资金汇总

展示已提现金额、绑定商户刷卡总额、提现率，以及会员与非会员的到账与提现率对比。

3.3 趋势图表

可切换时间范围（如近 7 天、近 30 天），查看：

  • 流水统计
  • 新增商户与充值商户趋势
  • 交易类型金额分布等

首页数据为汇总展示，明细请到对应业务菜单查询。

四、门户中心

菜单路径： 门户中心

将您有权限的功能按模块做成卡片，点击卡片可快速进入该模块下的第一个功能页。适合权限较多、需要快捷入口的场景。

若显示「暂无可用入口」，说明当前账号未分配业务菜单，请联系管理员。

五、品牌管理

用于维护支付品牌、机具及刷卡相关数据。

子菜单 主要用途
品牌列表 新增、编辑品牌；查看入库、绑定、激活数量；绑定机具
机具列表 查看与管理机具信息
刷卡记录 查询机具刷卡流水
风控管理 查看与处理风险相关配置与记录
协议管理 维护商户需签署的协议内容

5.1 品牌列表常用操作

  • 添加品牌： 填写品牌名称、激活条件、返佣等信息
  • 编辑： 修改品牌资料
  • 绑定机具： 为品牌关联机具号码
  • 使用状态开关： 关闭后该品牌相关能力可能受限，请谨慎操作

六、商户管理（核心模块）

日常运营最常使用的模块之一。

子菜单 主要用途
商户列表 查看商户资料、额度与资金状态，执行日常操作
提现列表 审核与跟踪商户提现
退款列表 审核商户充值后的全额退款申请
兑换券管理 管理兑换券发放与使用
充值赠品发货 处理充值活动赠品的发货状态
商品管理 维护 H5 端可选商品
额度包管理 维护充值套餐（额度、价格、说明等）

6.1 商户列表

6.1.1 列表字段说明（常用）

字段 含义
机具号码 商户绑定的机具
微信用户 商户在微信侧的昵称/标识
会员级别 如普通会员、银卡会员等及开通时间
剩余额度 当前可用于业务的额度
充值金额 累计充值相关金额
待提现 / 已提现 提现中及已到账金额
冻结金额 暂不可用的资金
使用状态 开关控制商户是否可用（1/2/3 为业务标记位）
协议 「已签署」可点击查看协议图片

6.1.2 顶部按钮

按钮 说明
重置 清空表头筛选，恢复默认列表
数据矫正 高级功能，批量修正历史数据，一般仅运维使用，勿随意点击
更新会员状态 同步微信支付侧的待处理充值/会员状态
导出 按类型导出商户相关数据
线下首冲额度 为指定手机号商户办理线下首次充值（选套餐提交）
模拟商户注册 测试用，模拟一名新商户注册

6.1.3 行内操作

操作 说明
积分明细 查看该商户积分按月汇总及明细
退款窗口 查看该商户距离「可退款窗口」还有多久，或窗口内还剩多少天；未充值商户会提示「该商户未充值」
删除协议 仅对已签署协议的商户：清空签署记录，商户需在 H5 重新签署

关于「退款窗口」：
商户充值后，在约定的锁定期满之后会进入短暂的「退款窗口」，窗口内可申请全额退款。点击「退款窗口」可查看当前处于锁定期还是窗口期，以及大约剩余天数，便于客服解答商户咨询。

6.2 提现列表

用于处理商户从平台提现到微信零钱的申请。

页面顶部：

  • 会员提现需审核 / 非会员提现需审核： 开关控制该类提现是否必须先经后台同意
  • 查询、刷新、导出

列表关注字段：

  • 提现金额、税费与手续费、应付金额
  • 是否打款、是否到账
  • 审核状态（如待审核、已通过、已拒绝等）

管理员操作（常见）：

  • 对待审核记录进行同意或拒绝
  • 查看失败原因（转账失败时）

页面顶部会汇总：总提现、总手续费+税费、总付款金额。

6.3 退款列表

用于审核商户在 H5 发起的充值全额退款（资金退回微信零钱）。

  • 审核流程与提现列表类似
  • 可配置「会员退款需审核」「非会员退款需审核」
  • 支持查看失败原因；部分环境在参数配置开启后，可对已同意的记录做开发联调用的撤销（一般生产环境勿用）

6.4 额度包管理

维护商户在 H5 充值时可选的套餐，包括额度、售价、套餐说明、关联商品等。修改后会影响新发起的充值，请与运营规则保持一致。

6.5 商品管理、兑换券、充值赠品发货

  • 商品管理： 配置展示商品、价格、库存等
  • 兑换券管理： 发放规则与核销情况
  • 充值赠品发货： 充值活动实物赠品的收货与发货状态

十、典型工作流程

10.1 客服：商户咨询「什么时候能退款」

  1. 打开 商户管理 → 商户列表
  2. 按微信昵称或机具号找到商户
  3. 点击 退款窗口
  4. 将弹窗中的说明转告商户；若提示「该商户未充值」，说明尚未完成额度充值

10.2 财务：处理一笔待审核提现

  1. 打开 商户管理 → 提现列表
  2. 筛选「待审核」
  3. 核对金额、商户身份与机具信息
  4. 点击 同意 或 拒绝（拒绝请填写原因）
  5. 后续在列表中查看是否打款、是否到账

10.3 运营：为商户办理线下首充

  1. 打开 商户列表 → 线下首冲额度
  2. 输入商户手机号，选择套餐
  3. 提交成功后，让商户在 H5 确认相关状态（如有）

10.4 运营：新增充值套餐

  1. 打开 额度包管理
  2. 新增或编辑套餐，填写额度、价格、说明
  3. 保存后，H5 充值页将展示新套餐

十一、常见问题

Q1：登录后菜单很少或没有业务菜单？
A：联系管理员检查您的角色与菜单权限是否已分配。

Q2：点击某页面提示无权限？
A：您的角色未包含该功能权限，需管理员在「角色管理」中勾选对应权限。

Q3：商户说提现一直不到账？
A：在「提现列表」查该单：是否已审核通过、是否已打款、到账状态及失败原因；必要时查「提现日志」。

Q4：「退款窗口」显示未充值，但商户称已付钱？
A：可能为线下未录入、支付未成功或数据未同步；可先「更新会员状态」，仍异常则联系技术支持核查充值记录。

Q5：导出数据与页面不一致？
A：导出一般按当前筛选条件生成；请确认筛选条件、时间范围后再导出。

Q6：误关了商户「使用状态」怎么办？
A：在商户列表找到该商户，将对应开关重新打开（需有操作权限）。

十二、联系与支持

  • 账号、权限、菜单问题：联系系统管理员
  • 业务规则（退款天数、提现限额等）：以参数配置及公司制度为准
  • 系统故障、数据异常：联系技术支持，并提供商户手机号、单号、操作时间

本手册根据当前系统功能整理，若菜单名称或按钮与线上一致性有差异，以实际页面为准。功能迭代后请以管理员通知或新版手册为准。
