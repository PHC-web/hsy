# 积分优化 — 甲方说明（白话）

## 一句话

商户长时间不登录时，系统会自动把「还没领走」的待返积分按周往下调一点；运营也可以保护指定商户、或关掉这项功能。用户手机里看不到「优化」字样，只会看到金额变了。

---

## 稍详细一点（几段话）

商户用机具刷卡产生流水后，系统会按规则算出以后几个月应返还的积分。其中还没领走的部分，叫「待返」。

有些商户很久不登录，待返却一直挂着。现在的「积分优化」就是针对这种情况：按照「多久没有登录」，按周自动下调这些还没领走的待返（大约每周保留七成五，相当于少四分之一）。如果一直不登录，就会每周继续下调；一旦商户登录了，计周会重新开始，但**已经减掉的部分不会加回去**。

运营侧可以做三件事：一是把个别商户加入白名单，加入后不受这项自动下调影响；二是在参数里关掉总开关，关掉后整体不再自动砍；三是打开某个商户查看每一档待返，必要时改金额，或指定某一档以后不要再自动优化。

系统一般会在每天凌晨自动检查并处理；后台也可以随时查看、预览或手动执行。用户端（手机 H5）不会出现「优化」相关说明，界面上只体现金额变化。

另外，「按流水多少来优化」还在规划中，目前没有启用，和现在这套「按登录时间优化」是分开的两套能力。
